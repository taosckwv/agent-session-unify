# agent-session-unify

把 Claude Code、Codex CLI、DeepSeek Harness（DSH）的会话记录统一成同一种格式，用于分析和优化。

## 状态

调研阶段已完成，实现尚未开始。结论见 `docs/RESEARCH.md`。

## 要解决的问题

- 三家的会话文件格式各不相同，且各自都有多代版本。
- 想知道一次会话里哪里可以优化：上下文怎么涨上去的、缓存命中如何、工具输出了多少、压缩前后差多少。
- 现有工具只能统计用量、或只能把事件转成 trace，没有一个能还原「每一步实际发出去的请求」。

## 两条线

- **A 线｜原始解析**：读各工具的原始会话文件，统一成同一套事件。字段不丢，认不出的原样保留。
- **B 线｜请求重建**：按事件回放，还原每一步真正发出去的 messages。有捕获的请求文件时用于核对。

A 线为准，B 线补齐与校验。细节见 `docs/RESEARCH.md` 第 8 节。

## 目录

```
docs/        调研结论与后续设计
src/         实现代码（技术栈待定）
tests/       测试与真实样本断言
scripts/     一次性分析脚本
```

## 数据安全

原始会话里含代码、路径与可能的凭据。**原始会话数据不入库**，只在本地处理；解析输出中凭据类内容必须替换成占位符。

## 下一步

1. 定技术栈，落最小可跑的 A 线解析器（先 DSH）。
2. 用真实样本建立断言：条数守恒、字段齐全、两次解析结果一致。
3. 再做 B 线回放，缺 system prompt 的段落标记为缺口。
